# データソース

国税庁の基幹統計 **民間給与実態統計調査**。e-Stat の「結果表（新たな復元推計手法により計算）」を使う。この系列は **2014–2024年（令和6年分）** を同一の復元推計で接続している。最新の公開日は 2025-09-26。

公式用語は「平均年収」ではなく **平均給与**（給与総額 ÷ 給与所得者数）。金額の表章単位は千円。

## 対象と母集団

- 対象は **民間の給与所得者**。公務員・自営業は含まない。
- 第8表以降（このダッシュボードが使う表）は **1年を通じて勤務した給与所得者**。
- 第1表・第2表は事業所用調査票で、1年未満勤続者を含む。計数は第8表以降と一致しないので混ぜない。
- 業種は事業所の業種ではなく、**所属企業の主業** で分類する。
- 正社員と正社員以外は企業規模表にしか無く、業種とは交差しない。業種別平均は両者の混在である。

## 取得する表

| キー | 統計表ID | 表 | 次元 | 用途 |
| --- | --- | --- | --- | --- |
| `industry-class` | `0004009620` | 全国計表 第9表 | 業種×給与階級×性別×年 | 業種ビュー（計行）と分布ビュー |
| `industry-age` | `0004009623` | 全国計表 第12表 | 業種×年齢×年 | 年齢ビュー。性別なし |
| `industry-tenure` | `0004009627` | 全国計表 第15表 | 業種×勤続年数×年 | 勤続ビュー。性別なし |
| `industry-bureau` | `0004009642` | 参考 国税局別表 第4表 | 業種×国税局×年 | 取得のみ。UI では使わない |

国税局別表は参考値で、源泉徴収義務者の所在地による。居住地の給与水準ではない。地図にすると都道府県SMRと同じ重みで読まれるため、配信 cube にも載せない。

## 業種（14分類＋合計）

日本標準産業分類（令和5年7月改定）に基づく粗分類。コードは e-Stat の `1`–`14`、合計が `15`。

電気・ガスなど標本が薄い業種は、抽出が従事員数層別のため精度が低い（調査の利用上の注意）。

## 給与階級

第9表の「200万円以下」などは累積ではなく隣接ブラケット（100万超〜200万）。表示では `100–200` のように読み替える。

## 配信ファイル

`scripts/build.ts` が `public/data/` に書く。

- `industry.json` — 第9表の給与階級「計」。industry × sex × year。平均給与・賞与・平均年齢・平均勤続・人員
- `dist.json` — 第9表の階級（計を除く）。industry × bracket × sex × year。人員
- `age.json` — 第12表。industry × age × year
- `tenure.json` — 第15表。industry × tenure × year

平均給与は千円のまま置く。画面では万円（÷10）で出す。

## 更新手順

```
npm run meta
npm run fetch
npm run data
npm run verify
```

`ESTAT_APP_ID` は `.env` に置く。生レスポンスは `data/raw/`（gitignore）。配信用 JSON は追跡する。
